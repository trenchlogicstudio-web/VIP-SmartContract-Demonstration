Run the local VIP engine

This guide opens in a browser. The guest, host and admin consoles run locally using Node.js and SQLite. Use Node 22.13 or newer on the 22 line, or Node 24 or newer. No package installation is required.

Run the two example receipts

Extract the ZIP and open a terminal in the package root or in the MVP folder. The example uses synthetic guests and leaves no database on disk.

npm run example

Open the guest console

npm start

While the process is running, visit the guest screen on this computer. Use a new guest ID and the €20,000 example. Review the terms before accepting. Hard-Stop blocks play on the checked line. Advisory alerts the host and permits a voluntary stop.

Replay past sessions

See what the policy would have cost on an operator’s own anonymised history: guest key, date and net loss per session. Nothing leaves the computer. From the MVP folder:

npm run replay -- samples/sessions-synthetic.csv

Verify the package

npm test

The full package compares the browser calculations, the SQLite engine and the separate in-memory reference. The original nine contract routes also work from existing integrations.
